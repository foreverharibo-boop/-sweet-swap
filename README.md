# 💝 sweet swap

**나와 캐릭터가 서로의 비밀 카드를 봉투에 넣어 교환하고, 그 내용으로 다음 장면을 시작하는 SillyTavern 확장이에요.**

> SillyTavern 1.18 이상에서 써요. 성인 캐릭터끼리의 역할극 전용이에요.

---

## 한눈에 보기

1. 내가 "이런 상황이 좋아"라고 **카드**를 써요.
2. 캐릭터도 자기가 원하는 **카드**를 AI가 대신 써줘요. (내 카드는 못 봐요!)
3. 두 카드를 **교환**해요.
4. **장면 시작**을 누르면, 카드 내용이 다음 답변에 숨은 지시로 붙어서 이야기가 이어져요.

편지를 주고받는 느낌이라고 생각하면 돼요. 서로 뭘 썼는지 모르는 채로 교환하는 게 재미 포인트예요.

---

## 처음 한 번만 하는 설정

1. **연결 프로필 만들기**: SillyTavern의 연결 프로필(Connection Manager) 기능으로, 카드를 만들 때 쓸 AI 연결을 하나 만들어 둬요.
2. **전용 연결 고르기**: 확장 탭에서 `💝 sweet swap`을 펼치고 `전용 연결`에서 방금 만든 프로필을 골라요.
3. **성인 확인**: 확장 메뉴의 `💝sweet swap`을 눌러 창을 열고, `⚙️ 설정` 탭에서 `등장인물은 모두 성인입니다`를 켜요. 이걸 켜야 카드 만들기가 돼요.

---

## 사용 방법 (기본 흐름)

`💝sweet swap` 창을 열면 위에 탭이 세 개 있어요.

| 탭 | 하는 일 |
|---|---|
| 💌 교환함 | 카드를 쓰고, 교환하고, 장면을 시작해요 |
| 🗝️ 비밀 서랍 | 보관해 둔 카드를 다시 꺼내 써요 |
| ⚙️ 설정 | 여러 가지 옵션을 바꿔요 |

### 순서

1. **내 카드 쓰기**: 제목, 원하는 상황, 장소, 분위기 등을 적어요. 다 채우지 않아도 되고, 하나만 적어도 돼요.
2. **`봉인하고 상대 카드 받기`** 를 눌러요. 잠깐 기다리면 캐릭터가 자기 카드를 써서 봉인된 채로 도착해요. 마음에 안 들면 `상대 카드 다시 받기`로 다시 받을 수 있어요.
3. **교환 방식**을 고르고 **`카드 교환하기`** 를 눌러요. (방식은 아래에서 설명해요)
4. 결과가 마음에 들면 **`장면 시작`** 을 눌러요. 그러면 AI가 카드 내용을 반영해서 다음 답변을 써요.
5. 이 카드를 나중에 또 쓰고 싶으면 **`비밀 서랍에 보관`** 을, 쓰고 나서 지우고 싶으면 **`카드 태우기`** 를 눌러요.

### 카드 칸 설명

| 칸 | 뜻 |
|---|---|
| 카드 제목 | 카드 이름이에요 |
| 원하는 상황 | 어떤 일이 벌어지면 좋을지 |
| 장소 | 어디에서 |
| 분위기 | 달달함, 긴장감 같은 느낌 |
| 상대에게 바라는 역할 | 상대가 어떤 태도나 관계였으면 하는지 |
| 꼭 포함할 요소 | 반드시 들어가야 하는 것 |
| 제외할 요소 | **절대 나오면 안 되는 것.** 양쪽 카드 모두에서 항상 지켜져요 |
| 비밀 메모 | 카드에만 남기는 한마디 |

---

## 교환 방식 6가지

| 방식 | 어떻게 되나요? |
|---|---|
| **블라인드 시작** | 카드 내용이 끝까지 안 보여요. 장면을 시작할 때 조용히 열려서 반영돼요. 가장 두근두근한 방식이에요. |
| **동시 공개** | 두 카드가 한꺼번에 다 보여요. |
| **부분 공개** | 상황, 장소, 분위기만 보이고 나머지는 봉인돼요. |
| **두 장 섞기** | AI가 두 카드를 합쳐서 **한 장짜리 새 카드**로 만들어 줘요. |
| **한 장 뽑기** | 두 카드 중 **한 장만 무작위로** 뽑혀요. 뽑힌 카드 내용만 쓰고, 뽑히지 않은 카드의 "제외할 요소"도 그대로 지켜져요. |
| **🎲 완전 랜덤 봉투** | 내 카드도 필요 없어요. AI가 캐릭터 정보는 모른 채로, 최근 대화 8개만 슬쩍 보고 완전히 무작위 봉투를 만들어요. |

> **두 카드가 서로 상반될 때**: 블라인드·동시 공개·부분 공개는 두 카드를 모두 쓰는 방식이에요. 장소나 분위기, 역할이 서로 달라도 한쪽을 지우거나 어중간하게 섞지 않고, 두 소원이 차례로 이뤄지도록 AI에게 지시해요. 그래도 "절대 안 돼"라고 적은 **제외할 요소는 항상 가장 먼저 지켜져요.**

### 🎲 완전 랜덤 봉투는 좀 특별해요

- 캐릭터 설정이나 내 페르소나는 **읽지 않아요.** 최근 대화만 참고해요.
- 장소는 지금 있는 곳을 유지하고, 상황과 분위기, 돌발 요소만 랜덤으로 바뀌어요. (갑자기 우주로 날아가지 않아요!)
- 절대 나오면 안 되는 것은 `랜덤 봉투에서도 제외할 요소` 칸에 적어 둘 수 있어요.
- 봉인된 채로 바로 시작해도 되고, `봉투 열기`로 먼저 확인해도 돼요. 마음에 안 들면 `다시 뽑기`, 다 쓰면 `봉투 태우기`를 눌러요.
- 최근에 나온 봉투 3장과 겹치지 않게 캐릭터별로 기억해요.

---

## 장면은 몇 번에 걸쳐 시작되나요? (턴 수 설정)

장면 시작을 누르면, 카드 내용이 **정해진 횟수만큼의 답변**에 걸쳐 적용돼요. 횟수가 끝나면 지시는 자동으로 사라져요.

- **1턴**: 한 번의 답변에서 바로 시작해요. 다만 한 번에 끝까지 몰아서 쓰지 않고, 도입 부분만 쓰도록 되어 있어요.
- **2턴**: 도입 → 본격 진행
- **3턴**: 장소 이동이나 준비 → 도착과 분위기 → 본격 진행 (천천히 이어가요)

`⚙️ 설정` 탭의 `모드별 장면 진행 턴 수`에서 방식마다 따로 고를 수 있어요.
기본값은 **🎲 랜덤 봉투만 1턴**, 나머지는 **3턴**이에요.

> 장면 진행 중에 답변을 **스와이프하거나 재생성**해도 단계가 꼬이지 않고 같은 단계로 다시 만들어져요. 대필(impersonate)이나 이어쓰기는 단계를 넘기지 않아요.

## 설정 탭 설명

| 설정 | 뜻 |
|---|---|
| sweet swap 사용 | 확장 전체를 켜고 꺼요 |
| 등장인물은 모두 성인입니다 | 켜야 카드 생성이 돼요 |
| 기본 교환 방식 | 처음 열었을 때 골라져 있는 방식 |
| 장면 시작 후 자동으로 카드 태우기 | 장면을 시작하면 카드를 자동으로 지워요. 비밀 서랍에 보관한 건 안 지워져요 |
| 캐릭터별 보관 개수 | 비밀 서랍에 캐릭터마다 몇 개까지 둘지. 넘으면 **오래된 것부터** 지워져요 |
| 모드별 장면 진행 턴 수 | 위에서 설명한 1~3턴 |

## 설치하기

1. `sweet-swap` 같은 이름으로 폴더를 하나 만들고, 파일 4개(`index.js`, `manifest.json`, `style.css`, `README.md`)를 그 안에 넣어요.
2. 그 폴더를 통째로 아래 위치에 넣어요.
   `SillyTavern/data/default-user/extensions/`
3. SillyTavern을 껐다가 다시 켜요.

## 알아두면 좋은 것들

### 데이터는 어디에 저장되나요?
- 카드, 초안, 비밀 서랍은 **캐릭터별(그룹 채팅은 그룹별)** 로 따로 저장돼요.
- 저장 위치는 **지금 쓰는 브라우저 안**이에요. 그래서 다음 점을 조심해야 해요.
  - 브라우저 데이터를 지우면 카드와 서랍이 **같이 사라져요.**
  - **폰과 PC는 서로 다른 저장소**라서 기록이 이어지지 않아요.
- 캐릭터 파일 이름을 바꾸면 새 캐릭터로 인식되어서 이전 기록이 안 보일 수 있어요.
- 작성 중인 내용은 자동으로 저장돼요.

### 내 비밀 메모를 캐릭터가 읽나요?
- 캐릭터 카드를 만들 때는 내 카드 중 **`제외할 요소`만** 넘어가요. 나머지(비밀 메모 포함)는 캐릭터 쪽 AI가 **보지 못해요.** 그래서 캐릭터의 메모는 답장이 아니라, 자기 소원을 자기 말투로 쓴 거예요.
- 하지만 **`두 장 섞기`** 를 하거나 **`장면 시작`** 을 누르면, 두 카드의 모든 내용이 AI에게 전달돼요. 이때 비밀 메모는 "분위기 힌트"로 쓰여요. (카드나 지시가 있다는 사실을 캐릭터가 말하진 않아요.)

### 다른 곳에는 영향이 없나요?
- 카드 만들기와 두 장 섞기는 **전용 연결 프로필**로 따로 요청해요. 지금 채팅에 쓰는 메인 연결의 API, 모델, 프리셋은 **바뀌지 않아요.**
- `장면 시작` 후의 실제 답변만 평소처럼 메인 연결로 만들어져요.
- 다른 확장이나 설정 파일은 건드리지 않아요.

### 카드가 이상하게 나오면요?
- 내용이 비어 있거나 형식이 잘못된 카드는 자동으로 한 번 다시 만들어요.
- 최근에 받은 카드 3장과 너무 비슷해도 한 번 다시 만들어요.
- 카드 내용은 항상 **한국어**로 만들어져요.
- 캐릭터 시트에 적힌 고정 취향(킨크)은 카드의 중심 소재로 쓰지 않도록 되어 있어요. 현재 장면과 관계에서 나오는 새로운 소원을 만들어서, 매번 같은 내용만 나오는 걸 줄여요.

## 문제가 생겼을 때

| 증상 | 해결 방법 |
|---|---|
| 카드 만들기가 안 돼요 | 확장 탭의 `전용 연결`이 골라져 있는지, `등장인물은 모두 성인입니다`가 켜져 있는지 확인해요 |
| "연결이 중간에 끊겼어요"가 떠요 | 카드를 만드는 동안 **화면을 켜 두고**, 다른 앱으로 넘어가지 말고 다시 시도해요 |
| 오래 걸려요 | 창 아래의 `취소`를 누르고 다시 시도해요. 창을 닫거나 채팅을 바꾸면 만드는 중이던 것도 취소돼요 |
| 카드는 잘 나왔는데 장면이 한 번에 끝나버려요 | `⚙️ 설정`에서 그 방식의 턴 수를 **2턴이나 3턴**으로 올려요 |
| 알림이 안 보여요 | 창이 열려 있을 때는 화면 위쪽에 알림이 잠깐 떠요 |
| 카드를 지웠는데 서랍에서도 없어졌어요 | `카드 태우기`는 현재 카드만 지우고, `기록 삭제`는 서랍의 기록을 지워요. 보관 개수를 넘으면 오래된 것이 자동으로 지워지는 점도 확인해요 |
