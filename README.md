# 💝sweet swap

SillyTavern 1.18+용 익명 판타지 카드 교환 확장입니다. 사용자와 현재 캐릭터가 각자의 카드를 봉인한 뒤, 선택한 방식으로 교환 결과를 다음 역할극 생성에 한 번만 적용합니다.

## 주요 기능

- 사용자 카드 작성 및 봉인
- 현재 캐릭터의 성격·관계·최근 채팅을 반영한 비밀 카드 생성
- 한 장 뽑기 / 두 장 섞기 / 블라인드 시작 / 동시 공개 / 부분 공개
- 교환 결과의 다음 본채팅 생성 1회 주입 및 자동 제거
- 캐릭터·그룹별 독립된 초안과 비밀 서랍
- 카드 태우기, 다시 받기, 보관한 카드 재사용
- 모바일 전체화면 UI

## 설치

1. ZIP을 풀어 `sweet-swap` 폴더 전체를 아래 경로에 넣습니다.
   - 사용자 확장: `SillyTavern/data/default-user/extensions/`
2. SillyTavern을 다시 시작합니다.
3. SillyTavern의 Connection Manager에서 카드 생성에 쓸 연결 프로필을 만듭니다.
4. 확장 설정의 `💝 sweet swap`을 펼치고 `전용 연결` 프로필을 선택합니다.
5. 확장 메뉴의 `💝sweet swap`을 눌러 교환함을 엽니다.
6. 최초 한 번, 설정에서 모든 등장인물이 성인임을 확인합니다.

## 사용 순서

1. 내 카드를 작성하고 `봉인하고 상대 카드 받기`를 누릅니다.
2. 교환 방식을 고르고 `카드 교환하기`를 누릅니다.
3. `장면 시작`을 누르면 현재 연결된 API로 본채팅 생성을 시작합니다.
4. 교환 지시는 해당 생성에만 숨겨서 적용된 뒤 자동 제거됩니다.

## 데이터와 동작

- 카드 데이터는 브라우저의 SillyTavern 저장소에 보관됩니다.
- 캐릭터 카드 생성과 `두 장 섞기`는 선택한 Connection Manager 프로필로 독립적인 백그라운드 AI 호출을 사용합니다.
- 백그라운드 호출은 SillyTavern 메인 연결의 API·모델·프리셋을 전환하거나 변경하지 않습니다.
- `장면 시작`으로 이어지는 본채팅 생성만 SillyTavern 메인 연결을 그대로 사용합니다.
- 다른 확장, 아카이브, 또또NSFW의 파일이나 설정을 수정하지 않습니다.
